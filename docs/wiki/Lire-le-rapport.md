# Lire le rapport

## 1. Le verdict, en haut

| Message | Signification |
|---|---|
| Le fichier est valide et ses tables sont chargées. | Aucun constat bloquant ni à corriger |
| Les tables sont chargées. Certains constats sont à corriger avant la remise. | Pas de blocage, mais des points à revoir |
| Le fichier comporte des constats bloquants : il serait rejeté en l'état. | **À corriger avant toute remise** |

## 2. « En résumé »

Quelques phrases en langage clair : l'état général du registre, les priorités, les tableaux les plus concernés. Commencez toujours par là.

## 3. Les trois scores

| Score | Ce qu'il mesure |
|---|---|
| **Score réglementaire** | Les règles officielles (EBA, ITS) et les contrôles techniques |
| **Score qualité** | Tous les contrôles, conseils de l'expert compris |
| **Confiance** | 100 si aucun constat bloquant, 0 sinon |

> Ces scores sont des **indicateurs internes**, sans valeur réglementaire : un score de 100 ne garantit pas l'acceptation du registre par l'autorité.

## 4. La gravité des constats

| Gravité | Que faire ? |
|---|---|
| **BLOQUANT** | Le fichier serait rejeté : corrigez impérativement |
| **MAJEUR** | Non-conformité probable : à corriger avant la remise |
| **MINEUR** | Qualité perfectible : à corriger si possible |
| **INFO** | Pour information, aucune action obligatoire |

## 5. Le détail d'un constat

Cliquez sur un constat pour l'ouvrir :

- **l'explication** en clair et la **référence** (règle EBA, article du règlement, note de l'ACPR) ;
- **Où** : le tableau, la colonne et la ligne concernés (ligne 1 = première ligne de données) ;
- **Le conseil de l'expert** : comment corriger, concrètement.

## 6. Vue réglementaire et vue experte

- **Vue réglementaire** : seulement ce qu'exigent les textes officiels.
- **Vue experte** : en plus, les conseils de l'expert, plus exigeants. *Un conseil n'est jamais une non-conformité réglementaire.*

## 7. Exporter

**Exporter les constats** produit un fichier CSV (pour Excel) ou JSON Lines.

- Cochez **Exclure les valeurs du registre** pour un export sans donnée confidentielle, que vous pouvez partager plus librement.
- Un export **avec valeurs** contient des données de votre registre : rangez-le là où votre DSI l'autorise.

Chaque export se termine par l'avertissement de l'outil (et, dans la version hors ligne, par la mention de l'absence des contrôles GLEIF).
