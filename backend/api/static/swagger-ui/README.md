# Swagger UI (fichiers embarqués)

Fichiers de [swagger-ui-dist](https://www.npmjs.com/package/swagger-ui-dist) version **5.33.1**,
sous licence Apache 2.0 (voir `LICENSE` et `NOTICE`).

Ils sont servis par l'API elle-même pour que la page `/docs` fonctionne sans accès internet et
sans appel à un CDN.

Pour mettre à jour : remplacer `swagger-ui-bundle.js`, `swagger-ui-bundle.js.LICENSE.txt`,
`swagger-ui.css` et `favicon-32x32.png` par ceux de la nouvelle version, puis modifier le numéro
de version ci-dessus.
